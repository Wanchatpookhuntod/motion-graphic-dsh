# หลักการออกแบบ — การสื่อสาร สี และงานหลายฉาก

อ่านก่อนเขียน storyboard เมื่อคลิปยาวกว่า 20 วินาที มีมากกว่า 6 ฉาก ต้องเปรียบเทียบของสองฝั่ง หรือผู้ใช้ขอให้ "ออกแบบดี ๆ" ไฟล์นี้บอกว่า **จะตัดสินใจอย่างไร** ส่วนวิธีวาดอยู่ใน `art.md` ทุกข้อจบด้วยสิ่งที่ต้องเขียนลง `STORYBOARD.md`

## 1. การสื่อสาร

**ข้อความเดียว** เขียนหนึ่งประโยค: "ดูจบแล้วคนดูจะ ___" ทุกฉากต้องรับใช้ประโยคนี้ ฉากที่ตัดออกแล้วประโยคยังครบ ให้ตัด

**ลำดับชั้น (hierarchy)** ทุกฉากมีสามระดับเท่านั้น และแยกกันด้วยอย่างน้อยสองตัวแปรจาก ขนาด / น้ำหนัก / สี / ตำแหน่ง / การเคลื่อนไหว

| ระดับ | หน้าที่ | ทำอย่างไร |
|---|---|---|
| 1 hero | สิ่งที่ต้องเห็นก่อน | ใหญ่ที่สุด สี accent ขยับก่อนหรือขยับคนเดียว |
| 2 รอง | อธิบาย hero | ขนาดราวครึ่งหนึ่ง สีหมึก เข้าหลัง hero 0.2–0.4 วิ |
| 3 บริบท | ป้าย หน่วย แหล่งที่มา | เล็ก สีหมึกจาง นิ่ง |

**Gestalt — สายตาจัดกลุ่มเองตามกฎนี้ ใช้มันแทนกรอบและเส้นแบ่ง**

| หลัก | ความหมาย | ใช้อย่างไร |
|---|---|---|
| ใกล้ชิด | ของที่อยู่ใกล้คือพวกเดียวกัน | ระยะในกลุ่ม ≤ ครึ่งหนึ่งของระยะระหว่างกลุ่ม ป้ายอยู่ชิดสิ่งที่มันอธิบาย |
| คล้ายกัน | สี/รูปทรงเดียวกันคือชนิดเดียวกัน | concept เดียว = สีเดียว รูปทรงเดียว ตลอดทั้งคลิป |
| ต่อเนื่อง | สายตาตามเส้นและแนว | จัดแนวขอบเดียวกัน ใช้เส้นหรือทิศการเคลื่อนไหวพาไปจุดถัดไป |
| ชะตาร่วม | ของที่ขยับพร้อมกันทิศเดียวกันคือกลุ่มเดียว | ของกลุ่มเดียวเข้าด้วย ease และทิศเดียวกัน ของต่างกลุ่มเข้าต่างจังหวะ |
| ภาพกับพื้น | ต้องรู้ทันทีว่าอะไรคือตัวเรื่อง | hero ต่างจากพื้นหลังด้วยความสว่างอย่างน้อย 40 จุด (สเกล 0–100) |

**เส้นทางสายตา** กำหนดลำดับ 1 → 2 → 3 ของทุกฉาก ของใหม่ต้องโผล่ใกล้จุดที่สายตาอยู่ล่าสุด ไม่ใช่ฝั่งตรงข้ามของเฟรม ฉากถัดไปเริ่ม hero ที่ตำแหน่งใกล้กับ hero ของฉากก่อน (match position) คนดูจะไม่ต้องหาใหม่

**ภาระการรับรู้** หนึ่งฉาก = หนึ่งความคิดใหม่ ขยับทีละอย่าง ข้อความบนจอไม่เกิน 7 คำต่อฉาก เวลาอ่านขั้นต่ำ = จำนวนตัวอักษรไทย ÷ 10 + 0.5 วินาที นับจากตอนที่ข้อความหยุดนิ่ง ภาพกับข้อความต้องเสริมกัน ไม่พูดซ้ำกัน

**เลือกภาพตามคำถาม**

| คนดูต้องการรู้ว่า | ใช้ |
|---|---|
| อันไหนมากกว่า | แท่งสองแท่งบนเส้นฐานเดียวกัน |
| กี่ส่วนจากทั้งหมด | แท่งเดียวแบ่งส่วน หรือบล็อกนับได้ (10 ช่อง, 100 ช่อง) |
| เปลี่ยนไปอย่างไรตามเวลา | เส้นที่วาดตัวเองซ้ายไปขวา |
| มากแค่ไหนในชีวิตจริง | ของจริงที่นับได้ (แก้ว ช้อน ก้าว) เทียบกับสิ่งที่คนรู้จัก |
| ก่อนกับหลัง / ผิดกับถูก | แบ่งเฟรมซ้าย–ขวา โครงเดียวกันทั้งสองฝั่ง ต่างเฉพาะตัวแปรที่เปรียบ |

**เปรียบเทียบให้ยุติธรรม** สองฝั่งใช้ขนาด ตำแหน่ง สเกล และจังหวะเดียวกัน ต่างได้อย่างเดียวคือสิ่งที่กำลังเปรียบ ฝั่งที่อยากให้จำอยู่ขวาหรือมาทีหลัง

→ ลง storyboard: ประโยคข้อความเดียว และในคอลัมน์ "ภาพ" ของแต่ละฉากระบุ hero กับลำดับสายตา

## 2. สี

**คิดเป็นสามแกน** hue (สีอะไร), value (สว่างแค่ไหน), chroma (สดแค่ไหน) ลำดับความสำคัญคือ value > chroma > hue ภาพที่แปลงเป็นขาวดำแล้วยังอ่านลำดับชั้นได้คือภาพที่สีทำงานถูก

**เลือกโครงสีจากสิ่งที่ต้องสื่อ**

| โครง | สร้างจาก | ให้ความรู้สึก | เหมาะกับ |
|---|---|---|---|
| เอกรงค์ | hue เดียว ไล่ value | สงบ จริงจัง หรูหรา | เรื่องเดียว ข้อมูลชุดเดียว แบรนด์ |
| ข้างเคียง | hue ห่างกันไม่เกิน 30–40° | กลมกลืน เป็นธรรมชาติ | ขั้นตอนต่อเนื่อง ธรรมชาติ สุขภาพ |
| คู่ตรงข้าม | hue ห่าง 180° | ตึง มีพลัง ตัดกันชัด | เปรียบสองฝั่ง ปัญหากับทางออก |
| ตรงข้ามเยื้อง | hue หลัก + สองสีข้างคู่ตรงข้าม | ตัดกันแต่นุ่มกว่า | สามหมวดที่มีหมวดหนึ่งเด่น |
| สามเส้า | hue ห่างกัน 120° | สนุก หลากหลาย | เด็ก เกม สามหมวดเท่าเทียม |

ใช้สัดส่วน 60–30–10: พื้น 60, สีรอง 30, accent 10 โครงไหนก็ตามให้สีเดียวเป็นใหญ่ สีที่เหลือลด chroma ลง

**อุณหภูมิ** สีอุ่น (แดง ส้ม เหลือง) พุ่งเข้าหาคนดู ให้ความรู้สึกเร่ง มีพลัง อาหาร ความใกล้ชิด สีเย็น (น้ำเงิน เขียวอมฟ้า ม่วง) ถอยออก ให้ความรู้สึกนิ่ง น่าเชื่อถือ เทคโนโลยี ใช้อุ่นกับ hero บนพื้นเย็นเมื่ออยากให้เด่น

**ความสด** พื้นที่สดจัดมีได้ที่เดียวต่อฉากและเล็ก พื้นหลังลด chroma เสมอ สีกลางย้อมไปทาง hue ของ accent เล็กน้อย ไม่ใช้เทาตายหรือ `#000` / `#fff` ล้วน

**สร้าง palette ด้วย OKLCH** (เขียนใน CSS ได้ตรง ๆ)

| บทบาท | พื้นสว่าง | พื้นมืด |
|---|---|---|
| พื้นหลัง | `oklch(97% 0.01 H)` | `oklch(18% 0.03 H)` |
| หมึกหลัก | `oklch(22% 0.03 H)` | `oklch(95% 0.01 H)` |
| หมึกจาง | `oklch(50% 0.03 H)` | `oklch(72% 0.03 H)` |
| accent | `oklch(58% 0.17 H)` | `oklch(78% 0.16 H)` |
| accent ที่สอง | หมุน H ตามโครงสี คง L และ C | เช่นเดียวกัน |

**ความหมายที่คนดูมีอยู่แล้ว** แดง = หยุด ผิด อันตราย, เขียว = ไป ถูก ปลอดภัย, เหลืองอำพัน = ระวัง, น้ำเงิน = ข้อมูล น่าเชื่อถือ ถ้าใช้สีเหล่านี้กับความหมายอื่นในคลิปเดียวกัน คนดูจะอ่านผิด

**บริบทไทย** ทอง = มงคล ศาสนา ความสำเร็จ; แดงคู่ทอง = เทศกาลจีน; ขาว–ดำล้วน = ไว้ทุกข์ เลี่ยงกับเรื่องรื่นเริง; สีประจำวัน (จันทร์เหลือง อังคารชมพู พุธเขียว พฤหัสส้ม ศุกร์ฟ้า เสาร์ม่วง อาทิตย์แดง) มีความหมายกับผู้ชมไทย; ในเรื่องสาธารณะหรือการเมือง อย่าใช้แดงกับเหลืองเป็นสองฝั่งที่ขัดกัน

**ตาบอดสี** ผู้ชายราว 1 ใน 12 แยกแดง–เขียวได้ยาก ห้ามใช้ hue อย่างเดียวบอกความต่าง ทุกคู่ที่ต้องแยกออกจากกันต้องต่างกันด้วย value อย่างน้อย 30 จุด **และ** มีไอคอน ป้าย หรือรูปทรงกำกับ คู่ที่ปลอดภัยคือน้ำเงินกับส้ม

**เฉพาะวิดีโอ** พื้นที่แดงสดขนาดใหญ่จะเบลอขอบหลังบีบอัด ให้ลด chroma หรือลดพื้นที่ ไล่สีเชิงเส้นเต็มจอบนพื้นมืดจะเป็นแถบ ให้ใช้ radial หรือสีพื้นแทน Contrast ตัวอักษร ≥ 4.5:1 และองค์ประกอบอื่น ≥ 3:1 (`check --json` ตรวจให้)

→ ลง storyboard: ชื่อโครงสีพร้อมเหตุผลหนึ่งวลี ค่า H ที่เลือก และบทบาทของแต่ละสี (พื้น / หมึก / accent / accent ที่สองใช้กับอะไร)

## 3. งานหลายฉาก

**แผ่นสไตล์ก่อนตาราง** เขียนเหนือตาราง storyboard ครั้งเดียว แล้วไม่เปลี่ยนกลางเรื่อง: palette ตามบทบาท, ขนาดตัวอักษรสามระดับ, ภาษารูปทรง (มุมมนเท่าไร เส้นหนาเท่าไร), ภาษาการเคลื่อนไหว (ease หลักหนึ่งตัว ระยะเวลาเข้า–ออกมาตรฐาน), พื้นหลังที่ใช้ร่วมทุกฉาก

**ความต่อเนื่อง** concept ที่กลับมาใช้สี รูปทรง และตำแหน่งเดิม การเปลี่ยนสไตล์หมายถึงเปลี่ยนเรื่อง อย่าเปลี่ยนเพื่อความหลากหลาย มี motif หนึ่งอย่าง (รูปทรง เส้น หรือการเคลื่อนไหว) ที่ปรากฏตั้งแต่ฉากแรกถึงฉากสุดท้าย

**จังหวะ** ความยาวฉากไม่เท่ากันทุกฉาก: เปิดสั้น กลางยาว จุดสำคัญได้เวลานิ่ง (hold) อย่างน้อย 1 วินาทีหลังทุกอย่างหยุด แต่ละฉากมีสามช่วง สร้าง → นิ่งให้อ่าน → ส่งต่อ ช่วงนิ่งห้ามสั้นกว่าเวลาอ่านขั้นต่ำ

**การเปลี่ยนฉากมีความหมาย** ตัดตรง = เรื่องเดียวกันต่อเนื่อง, เลื่อนไปทางเดียวกัน = ลำดับถัดไป, ซูมเข้า = ลงรายละเอียด, ซูมออก = สรุปภาพรวม, เปลี่ยนสีพื้น = เปลี่ยนหัวข้อ ใช้ชนิดเดียวกับความหมายเดียวกันตลอดเรื่อง

**ความหนาแน่น** สลับฉากแน่นกับฉากโล่ง ฉากที่มีตัวเลขสำคัญที่สุดควรโล่งที่สุด

→ ลง storyboard: แผ่นสไตล์เหนือตาราง และในคอลัมน์ "การเคลื่อนไหว" ระบุชนิดการเปลี่ยนฉากพร้อมความหมาย

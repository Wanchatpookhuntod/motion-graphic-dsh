# Style guide (from the reference lesson clip)

Topic-neutral. The examples come from the reference clip (a lesson on success metrics for content creators) only to show the shape; reuse the shape, never the content.

## 1. Lesson shape

| # | Scene | What it does | Reference length |
|---|---|---|---|
| 1 | **Hook: contrast question** | Two concrete cases with numbers → "ไหน…กว่ากันครับ" → "ถ้าคุณตอบว่า …" → "วันนี้ผมจะพาคุณไปดูว่าทำไมคำตอบนั้นอาจจะผิด" + why it matters long-term. | ~20 s |
| 2 | `[[INSTRUCTOR]]` greeting | "สวัสดีครับ / ขอต้อนรับเข้าสู่หลักสูตร… / สาขา… / คณะ… / มหาวิทยาลัย…" one unit per line, then the card. | ~25 s with card |
| 3 | **Key question** | "ก่อนที่เราจะ… เราต้องตอบคำถามหนึ่งให้ได้ก่อน นั่นคือ / [คำถาม]" + the cost of getting it wrong, escalating ("และที่แย่กว่านั้นคือ…"). | ~20 s |
| 4 | **Framing: three things** | "ในคลิปนี้ [x] นาที เราจะคุยกันสามเรื่อง / หนึ่ง… / สอง… / และสาม…". | ~15 s |
| 5…  | **Definitions, one term per scene** | Recipe in section 2a. | 15–35 s each |
| … | **Weighting / nuance** | "แต่เดี๋ยวนะครับ / ทั้ง N อย่างนี้น้ำหนักไม่เท่ากัน" then one line per item, from light to heavy, each with the reason. | ~25 s |
| … | **Trap concept** | Name + Thai gloss, what it is, and "ที่สำคัญคือ มันเปลี่ยนพฤติกรรมเราไปในทางที่ผิด". | ~15 s |
| … | **Paired real case** | Recipe in 2b. Ends with the hook question again. | ~40 s |
| … | **Check-tool: three questions** | "แล้ววิธีเช็คง่าย ๆ คืออะไร / ผมให้คำถามคุณสามข้อครับ / หนึ่ง… สอง… และสาม…" then the verdict line "ถ้าคำตอบคือ ไม่… ไม่… และ… / นั่นคือ [trap] ครับ". | ~20 s |
| … | **Goal → what to watch** | "ทีนี้คำถามคือ แล้วเราควร… / คำตอบคือ ขึ้นอยู่กับว่า…" then "แบบที่หนึ่ง [English] คือ [Thai] / ตัวชี้วัดที่ตรงคือ…" for three types. Add one "ไม่ใช่… นะครับ แต่เป็น… เพราะ…" correction. | ~50 s |
| … | **One action** | "สิ่งที่ผมอยากให้คุณทำหลังดูคลิปนี้จบคือ / เลือกมาหนึ่งข้อ / แค่หนึ่งข้อ" + the limit and why + a closing maxim in two halves ("…ที่ดี ต้องนำไปสู่… / ไม่ใช่นำไปสู่…"). | ~30 s |
| … | **Recap** | "สรุปสามเรื่องที่เราคุยกันวันนี้นะครับ / หนึ่ง… สอง… และสาม…" — same three names as the framing, one rule each. | ~20 s |
| … | **Homework** | "งานที่ผมอยากให้คุณทำก่อนเข้าห้องเรียนคือ" + 3–4 concrete steps (open, look at three…, notice…, write down) + "เราจะเอามาใช้ต่อในคลิปถัดไป". | ~20 s |
| last | **Teaser + goodbye** | "ทีนี้พอเรารู้แล้วว่า… / คำถามถัดไปที่ยากกว่าคือ…" + "คลิปหน้าผมจะให้เครื่องมือหนึ่งชิ้นกับคุณ / ชื่อว่า…" + how long it will be used + "สำหรับคลิปนี้สวัสดีครับ". | ~25 s |

Not every clip needs every middle scene; keep the frame (hook, greeting, key question, three things, … , recap, homework, teaser) and pick middle recipes that fit the content. The three things in framing, body and recap must match in count, names and order.

## 2. Scene recipes

**2a. A definition**
1. `[Term]` alone at the start of the line, then "คือ …" in plain Thai.
2. A catch the viewer would miss: "สังเกตนะครับว่าผมพูดว่า… / ไม่ได้แปลว่า…".
3. A tiny worked example with numbers ("คนหนึ่งคนเห็นสามรอบ / Impression เท่ากับสาม / แต่ Reach เท่ากับหนึ่ง").
4. Close with **"มันตอบคำถามว่า …"** — every term answers one question. For a risky term, close with advice instead: "เพราะฉะนั้น… อย่าเพิ่ง… / ให้ถามก่อนว่า…".

**2b. Paired real case**
- One ordinary, local, believable subject ("สมมติมีร้านกาแฟเล็ก ๆ ในลพบุรี") — use a place the audience knows.
- Case A: the flashy result, the emotion ("เจ้าของดีใจมาก"), the real outcome ("แต่ยอดขายสัปดาห์นั้นเท่าเดิม ทำไมครับ"), two reasons.
- Case B: "เทียบกับอีกคลิปหนึ่ง ร้านเดียวกันนี้" — small headline number, but the meaningful numbers (saves, questions) and a real-world result.
- Repeat the hook question ("…ไหนสำเร็จกว่าครับ"), then the lesson as a contrast sentence "ตัวเลขที่ทำให้เรารู้สึกดี / กับตัวเลขที่บอกว่าเรากำลังไปถูกทาง".

**2c. Escalation and turns** — the voice moves with small spoken turns, one per line: "แต่เดี๋ยวนะครับ", "ทีนี้มาถึงเรื่องที่ผมอยากให้คุณระวังที่สุด", "และที่สำคัญคือ", "ทีนี้คำถามคือ", "คำตอบคือ", "ทำไมต้อง… เพราะ…".

## 3. Voice and line rules

- Narrator **ผม** speaks to **คุณ**; **เรา** for the course together. Warm, direct, a lecturer talking to one student; no hype, no news-reader tone.
- **One line = one breath = one subtitle.** Reference average 32 characters; aim ≤ 40, hard limit 46 (the converter warns). Split at spoken pauses; a list marker ("หนึ่ง", "และสาม") may sit at the end of the previous line or start its own.
- "ครับ" / "นะครับ" on about one line in eight to ten — on questions, turns and verdicts, not on every line.
- Questions to the viewer are frequent and then answered by the narrator ("ทำไมครับ", "แล้ว…คืออะไร").
- English terms: keep the English on screen, give the Thai reading for TTS (`Vanity Metrics || แวนิตี้ เมตริกส์`), and gloss in Thai at first use ("หรือตัวชี้วัดปลอบใจ"). Numbers on screen as digits only if the picture needs them; the spoken side always in words.
- Repetition is a tool: "เลือกมาหนึ่งข้อ / แค่หนึ่งข้อ"; maxims in two balanced halves.
- No placeholders, no unsupported multipliers, no "ในคลิปนี้เราจะมาพูดถึง" without the count of things.

## 4. Write for the picture

Each line will be drawn; nothing appears before it is spoken.
- Concrete nouns, numbers and actions over abstractions; one new visual object per line.
- Contrasts as parallel lines of the same shape (Case A / Case B, Impression = 3 / Reach = 1).
- Lists, weights and check questions one item per line, so each enters when spoken.
- Quotes of people in “…” on their own line (they become bubbles).

## 5. Facts

Platform definitions, metrics, prices, rules change: search, cite source and date in the delivery notes, word it to age well ("ในปัจจุบัน", "ณ ปี …"). Fictional examples are fine; keep them ordinary and local.

## 6. Checklist

- [ ] Hook is a two-case contrast question that invites a wrong answer, then promises why.
- [ ] Greeting + `[[INSTRUCTOR]]` after the hook, one unit per line.
- [ ] Key question stated, with the cost of getting it wrong.
- [ ] Framing names three things with the clip length; body and recap use the same names in the same order.
- [ ] Each term: "คือ…", a catch, a tiny number example, "มันตอบคำถามว่า…".
- [ ] One paired real case, same subject, ends with the hook question.
- [ ] A check-tool or mapping the viewer can reuse; one action with a limit and a maxim.
- [ ] Homework with concrete steps, linked to the next clip; teaser names the next tool/topic; ends "สำหรับคลิปนี้สวัสดีครับ".
- [ ] Lines ≤ 46 characters (most ≤ 40); every English term / number has a `||` spoken form and a Thai gloss.
- [ ] Estimated length within ±10 % of the target; stale facts checked and cited.

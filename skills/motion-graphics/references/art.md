# หลักการวาดภาพ — SVG สำหรับ HyperFrames

อ่านก่อนวาด ไฟล์นี้สั้นโดยตั้งใจ: ทุกข้อใช้กับ composition ของ HyperFrames (timeline ของ GSAP ที่ถูก seek ทีละเฟรม) ไม่มี helper, template หรือคลังภาพอื่นให้ค้น — วาดเป็น inline SVG ในไฟล์ composition โดยตรง

## 1. คิดก่อนวาด

1. **หนึ่งภาพ = หนึ่งความหมาย** เขียนหนึ่งบรรทัดก่อนแตะโค้ด: ภาพนี้หมายถึงอะไร จุดโฟกัสอยู่ไหน สีเน้นอยู่ตรงไหน
2. **Silhouette ก่อนรายละเอียด** ย่อเหลือ 60 px แล้วยังเดาออกว่าคืออะไร
3. **ชัดก่อนสวย** รูปทรงอ่านง่ายชนะ gradient เงา และ texture เสมอ
4. **รายละเอียด 2–3 อย่างพอ** บ้านหนึ่งหลัง = หลังคา ประตู หน้าต่าง เส้นพื้น
5. **ทิศทางคือความหมาย** ลูกศรชี้ทางที่เรื่องเดิน กราฟโตซ้ายไปขวา คนหันหาสิ่งที่มอง

ลำดับการเลือก: ของที่มีอยู่ใน registry (`catalog`, `add`) → inline SVG ที่วาดเอง → canvas เฉพาะเมื่อมีหลายร้อยชิ้น ห้ามวาดเลียนโลโก้ ตัวละครมีลิขสิทธิ์ หรือรูปที่ผู้ใช้ให้มา ให้ใช้ไฟล์จริง

## 2. กฎการเขียน SVG

- เส้น 2–3 หน่วย viewBox, `stroke-linecap="round"` และ `stroke-linejoin="round"` เสมอ
- viewBox ราว 100–200 หน่วย กำหนด `width` อย่างเดียวหรือให้ `height = width × viewBoxH / viewBoxW` ห้ามยืด
- สีมาจาก CSS variable ของ composition (`var(--accent)`, `var(--ink)`, `var(--paper)`) ไม่ hard-code hex ซ้ำในแต่ละรูป
- fill = accent อ่อน (`fill-opacity` .16–.28) + เส้นขอบ accent เต็ม บนตัววัตถุไม่ใช้ gradient หนัก, drop shadow, texture (ชั้นพื้นหลังของเฟรมเป็นอีกเรื่อง ดูข้อ 3) เว้นแต่ถูกสั่ง
- เส้นพื้นยึดวัตถุได้ดีกว่าเงา
- ลำดับ layer: เส้นพื้น → ของข้างหลัง → ตัวหลัก → รายละเอียด → accent → ชิ้นที่ขยับ
- `id` ของ clipPath / mask / marker ต้องไม่ซ้ำทั้งหน้า เติมชื่อ scene นำหน้า
- ชิ้นที่จะขยับแยกเป็น `<g id="...">` ของตัวเอง ตัวเลขสัดส่วนสำคัญประกาศไว้ที่เดียว ไม่เดา path string

## 3. Composition (เฟรม 1920×1080)

การจัดเฟรม ขนาด ความหนาแน่น และพื้นหลัง ให้ยึด `creative/video-composition.md` และ `creative/house-style.md` เป็นหลัก ตารางข้างล่างเป็นตัวเลขเสริมสำหรับเฟรม 1920×1080 ถ้าขัดกัน ให้ทำตามสองไฟล์นั้น

| หลัก | ตัวเลข |
|---|---|
| Hero | หนึ่ง beat มี hero เดียว ใหญ่กว่าอย่างอื่น 2–3 เท่า และมีจุดรองอีกหนึ่งจุดให้สายตาเดินไปต่อ (ภาพคู่กับตัวเลข, ตัวเลขคู่กับป้าย) |
| ตัวอักษร | 3 ระดับ: hero 160–320 px (ตัวเลขสำคัญใหญ่ได้ถึง 400 px), title 72–110 px, label 40–56 px — ไม่ต่ำกว่า 40 px |
| เติมเฟรม | กลุ่มเนื้อหากว้าง 70–90% ของเฟรม และสูงอย่างน้อย 55% ของเฟรม ถ้าเล็กกว่านี้ให้ขยาย ไม่ใช่เติมของ |
| โครงเฟรม | **แบ่งโซน ไม่ลอยกลาง**: ข้อความยึดขอบซ้ายที่ x ≈ 200 px ภาพอยู่ครึ่งขวา (หรือกลับกัน) ใช้โครงเดียวกันทุกฉาก จัดกลางทั้งจอได้เฉพาะฉากเปิดหรือฉากปิดที่ตั้งใจให้นิ่ง |
| Safe area | เนื้อหาอยู่ใน 90% ของเฟรม ข้อความสำคัญอยู่ใน 80% ไม่มีชิ้นไหนชิดขอบน้อยกว่า 96 px หรือทับกัน |
| ระยะห่าง | ทวีคูณของ 24 px ขอบในอย่างน้อย 96 px |
| ไอคอนและของนับได้ | ชิ้นเล็กสุดที่ต้องดูออกว่าคืออะไร กว้างไม่ต่ำกว่า 90 px เส้นขอบ 4–6 px ที่ขนาดเฟรมจริง |
| Unity | สไตล์ภาพเดียว easing ตระกูลเดียว วิธีเข้าแบบเดียวกันสำหรับของชนิดเดียวกัน หักจังหวะเฉพาะ beat สำคัญ |

**ชั้นของเฟรม** วิดีโอไม่ใช่หน้าเว็บ ทุกฉากมีสามชั้น และชั้นหลังใช้ร่วมกันทั้งคลิป:

| ชั้น | ใส่อะไร | ค่า |
|---|---|---|
| หลัง | 2–3 อย่างจาก: ตัวเลขหรือคำยักษ์จาง ๆ ที่เกี่ยวกับฉาก, glow วงกลมสี accent, ลายจุดหรือเส้นตาราง, แผ่นสีครึ่งเฟรม | ความทึบ 8–18% ขยับช้ามากบน timeline (เลื่อน 20–40 px หรือ scale 1 → 1.04 ตลอดฉาก) |
| กลาง | เนื้อหา: hero จุดรอง ข้อความ | ตามตารางข้างบน |
| หน้า | 1–2 อย่างจาก: เส้นกำกับแนวตั้งข้างหัวข้อ, ป้ายหมวดเล็ก, เลขฉาก `02 / 05`, เส้นคั่นที่วาดตัวเอง | หมึกจาง ขนาด label |

พื้นหลังต้องไม่ใช่สีเรียบล้วน แต่ห้ามไล่สีเชิงเส้นเต็มจอบนพื้นมืด (เป็นแถบหลังบีบอัด) ใช้ radial หรือสีพื้นกับ glow เฉพาะจุด ไม่ใช้ `#000` / `#fff` ล้วน ให้ย้อมไปทาง hue ของ accent

**ไม่มีเฟรมว่าง** ตั้งแต่วินาทีที่ 0 ถึงเฟรมสุดท้ายต้องมีเนื้อหาชั้นกลางอยู่บนจอเสมอ ฉากถัดไปเริ่มเข้าก่อนฉากเดิมออกหมด หรือออกกับเข้าทับกันอย่างน้อย 0.2 วินาที เมื่อ snapshot ให้รวมเวลาที่เป็นรอยต่อฉากหนึ่งจุดเสมอ

ภาพก่อน ข้อความทีหลัง: บนจอเหลือแค่คำสำคัญ ตัวเลข หรือ label คำเดียว ตัวเลข → counter หรือแท่งกราฟ, ผิด/ถูก → กากบาทหรือเช็ก, กระบวนการ → ของเคลื่อนตามเส้นทาง เคลื่อนไหวเบา ๆ (ลอย พัลส์) ใส่ได้เฉพาะ hero

## 4. สี

60-30-10: พื้นกลาง ๆ เป็นหลัก, **accent เดียวต่อ scene**, แดง/เขียวสงวนไว้สำหรับคำตัดสินผิด/ถูก ตัวอักษร contrast ≥ 4.5:1, ส่วนที่ไม่ใช่ตัวอักษร ≥ 3:1 (`check --json` รายงานและเสนอ `suggestedColor`)

| mood | ใช้กับ | accent |
|---|---|---|
| ใส สดชัด | กลาง ๆ ทุกเรื่อง คอร์สออนไลน์ | `#2a78d6 #6250d6 #e76530 #0aa06e #d56a93` |
| Digital Calm | เทคโนโลยี การเงิน สุขภาพ ภาครัฐ | `#2563eb #0f9d9a #7c5cdb #b88309 #5b7087` |
| Warm Earth | วัฒนธรรม อาหาร ท่องเที่ยว ชุมชน | `#c2622d #ba8301 #7a8b3a #2f7f7a #8c4a6b` |
| Edu Pop | เด็ก การศึกษา โซเชียลสั้น | `#3b82f6 #c67e04 #ec4899 #8b5cf6 #049bb5` |
| ไทยโทน | ประวัติศาสตร์ วัฒนธรรมไทย | `#1f4e8c #ac8807 #c8422c #2e8b6e #6b3f7a` |

เลือกหนึ่งแถว ประกาศเป็น variable ที่ root แล้ว concept เดียวกันใช้สีเดิมทั้งคลิป ถ้าผู้ใช้ให้ palette มา ใช้ของผู้ใช้

## 5. ขยับชิ้นส่วน

ทุกการเคลื่อนไหวเป็น tween บน timeline ของ composition (สัญญาอยู่ใน skill `mg-hyperframes`) ไม่มี CSS animation ที่วนเอง ไม่มี `requestAnimationFrame` ไม่มี `Math.random`

- **วัตถุเข้า**: `tl.from("#bowl", { scale: 0.6, opacity: 0, duration: 0.5, ease: "back.out(1.6)" }, 1.2)` — tween ที่ `<g>` หรือ wrapper ไม่ใช่ที่ `.clip`
- **เส้นวาดตัวเอง**: วัดความยาวจริงตอนสร้าง ก่อนประกาศ timeline — ห้ามใช้ `pathLength="1"` (ทดสอบแล้วเส้นไม่ถูกวาด):
  ```js
  const el = document.querySelector("#roof");
  const len = el.getTotalLength();
  gsap.set(el, { strokeDasharray: len + " " + len * 1.2, strokeDashoffset: len * 1.1 });
  tl.to(el, { strokeDashoffset: 0, duration: 0.6, ease: "power2.out" }, 2);
  ```
  offset เริ่มที่ `len * 1.1` เพื่อไม่ให้ปลายมน (round cap) โผล่เป็นจุดก่อนเส้นเริ่มวาด เส้นประวาดตัวเองแบบนี้ไม่ได้ ให้ fade แทน
- **รูปในกล่อง SVG ถูกตัดขอบ**: ชิ้นที่ scale หรือเลื่อนออกนอก viewBox ต้องมี `overflow="visible"` บน `<svg>` หรือเผื่อขอบใน viewBox
- **รูปทรงอินทรีย์ขนาดเล็กอ่านไม่ออก** (รอยเท้า มือ ใบหน้า สัตว์): อย่าวาดแล้วแก้วน ถ้ารอบแรกดูไม่ออกว่าคืออะไร ให้เปลี่ยนเป็นตัวเลข แถบ จุด วงแหวน หรือลูกศรที่สื่อความหมายเดียวกันทันที
- **หมุนรอบตัวเอง**: ตั้ง `transformOrigin: "50% 50%"` ใน tween หรือ `svgOrigin` เป็นพิกัด viewBox ของข้อต่อ
- **ตัวละคร**: หนึ่ง `<g>` ต่อหนึ่งข้อพับ หมุนรอบข้อ ไม่เลื่อนเป็นเส้นตรง หัวตามลำตัวช้ากว่า 10–20%
- อย่าใส่ CSS `transform` บน element ที่ GSAP จะ transform

## 6. ก่อนส่ง

- [ ] เขียนความหมายของแต่ละภาพได้หนึ่งบรรทัด และภาพสื่อตรงนั้น
- [ ] hero ใหญ่กว่าเพื่อน 2–3 เท่า ข้อความไม่ต่ำกว่า 40 px อยู่ใน safe area
- [ ] กลุ่มเนื้อหากว้าง 70–90% ของเฟรม แบ่งโซนซ้าย–ขวา มีชั้นหลังและชั้นหน้า
- [ ] ไม่มีเฟรมว่างที่รอยต่อฉาก ไม่มีชิ้นไหนชิดขอบหรือทับกัน
- [ ] accent เดียวต่อ scene ลูกศร กราฟ และทิศทางการมองถูกความหมาย
- [ ] ตัวอักษรไทยใช้ฟอนต์ที่โหลดด้วย `@font-face` ไม่ถูกตัดสระบน/ล่าง
- [ ] บอกผู้ใช้ตามจริงว่าอะไรยังไม่ได้ตรวจด้วยตา

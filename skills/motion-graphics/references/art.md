## 0. หลักคิด 5 ข้อ (ก่อนหยิบปากกาขึ้นมา)

1. **หนึ่งภาพ = หนึ่งความหมาย** เขียนออกมาหนึ่งบรรทัดก่อนแตะโค้ด: ภาพนี้หมายถึงอะไรในคำบรรยาย จุดโฟกัสคือส่วนไหน สีเน้นอยู่ตรงไหน
2. **Silhouette มาก่อนรายละเอียด** ถ้าดูแค่เงาตอนย่อเหลือ 60 px แล้วเดาไม่ออกว่าคืออะไร แปลว่าแบบยังไม่ผ่าน
3. **ชัดก่อนสวย** ของเล่นของภาพ (gradient, เงา, texture) แพ้รูปทรงที่อ่านง่ายเสมอ
4. **รายละเอียด 2–3 อย่างก็พอ** — บ้านหนึ่งหลังต้องการแค่หลังคา ประตู หน้าต่าง และเส้นพื้น
5. **ทิศทางคือความหมาย** ลูกศรชี้ไปทางที่เรื่องดำเนิน กราฟโตซ้าย→ขวา คนหันหน้าเข้าหาสิ่งที่กำลังมอง (จุดนี้พลาดมาแล้วจริง)

## 1. เลือกเทคนิคตามลำดับนี้ (อย่าข้ามขั้น)

| ต้องการ | ใช้อะไร | เพราะ |
|---|---|---|
| คำนามทั่วไป (ตา หัวใจ นาฬิกา ผู้ใช้) | ไอคอนสำเร็จ (Material Symbols) | คงเส้นคงวาและไม่มีความเสี่ยง |
| วัตถุเฉพาะ / ฉากเล็ก (บ้าน โทรศัพท์ ตราชั่ง กรวย funnel) | inline SVG helper `svgXxx(c,w)` | คมที่ 1920 px, แต่งสีด้วย CSS var, animate ได้ทีละชิ้น, seek ได้ |
| ของเยอะ เคลื่อนเยอะ pattern / burst / เส้นทาง | canvas `CV()` + `DRAW.xxx` | หลายร้อยชิ้นยังถูก และ redraw จาก timeline ได้เป๊ะ |
| ฟุตเทจ / รูปจริงของผู้ใช้ | frame sequence | ห้ามวาดเลียนของที่ผู้ใช้ให้มา |

**ห้ามใช้ p5.js หรือ three.js** ใน engine แบบ timeline เพราะมันรันนาฬิกาของตัวเอง (`draw()` / `requestAnimationFrame`) ทำให้ scrub และ export mp4 แบบ frame-exact คุมไม่ได้ และกินขนาดไฟล์ ถ้าอยากได้ look 3D ให้ fake ใน SVG (isometric, สองเฉดต่อหนึ่งหน้า) หรือถามผู้ใช้ก่อน

**ค้นคลังก่อนวาดใหม่** — ดู `assets/illustrations/index.md` แล้วตามด้วย `<series>/shared/*.js` ของโปรเจกต์นั้น

## 2. กฎ 8 ข้อของการเขียน SVG

1. **เส้น** 2–3 px ในหน่วย viewBox พร้อม `stroke-linecap="round"` และ `stroke-linejoin="round"` เสมอ
2. **สี** ใช้ CSS variable เท่านั้น (`var(--acc)`, `ca..ce`, `var(--text-primary)`) — ห้าม hard-code hex ใน scene เพราะจะพังในโหมดสว่าง/มืด
3. **Fill** = accent อ่อน (`fill-opacity` .16–.28) + เส้นขอบ accent เต็มความเข้ม ส่วนกลาง ๆ ใช้ `var(--surface-2)` / `var(--border-stronger)`
4. **ห้าม** gradient หนัก, drop shadow, texture — เว้นแต่ผู้ใช้สั่ง
5. **เส้นพื้น** (ground line, 3 px, `var(--border-stronger)`) ยึดวัตถุให้อยู่กับที่ ได้ผลกว่าเงา
6. **Layer order**: เส้นพื้น → ของข้างหลัง → ตัวหลัก → รายละเอียด → ส่วน accent → ชิ้นที่ขยับ
7. **Id ของ clipPath / mask / pattern / marker ต้องไม่ซ้ำ** ให้เติมชื่อ scene นำหน้า (id เป็น global ทั้งหน้า)
8. **สัดส่วน viewBox** ต้องไม่ยืด: height = `w * viewBoxH / viewBoxW` — ตั้ง viewBox ราว 100–200 หน่วย

## 3. ขั้นตอนวาด: ทำเป็น pass ไม่ใช่ม้วนเดียว

1. **Composition** — ขอบเขต พื้นที่ว่าง เงาหลัก (dominant silhouette) ลำดับ layer
2. **Structure** — มวลใหญ่ ๆ ด้วยของแข็งง่าย ๆ (วงกลม กล่อง ทรงกระบอก) ใส่ใน `<g>` ที่ตั้งชื่อไว้ตรวจได้
3. **Geometry** — เส้นโค้งที่ตั้งใจไม่กี่เส้น จุดต่อ จุดทับ คำนวณจุดจากตัวเลขที่ประกาศไว้บนหัว helper ห้ามเดา path string
4. **Style** — ช่องสี ความหนาเส้น ส่วน accent
5. **Review** — render แล้วแก้ "ตำหนิที่ใหญ่ที่สุด" ก่อน

> รายละเอียดไม่สามารถซ่อมรูปทรงที่ผิดได้ — ถ้าดูแล้วไม่เหมือน ให้ย้อนกลับไป pass ที่พัง ไม่ใช่เติมรายละเอียด

**ตัวเลขที่สำคัญ** (สัดส่วน จำนวนชิ้น) ให้ประกาศไว้บนหัว helper หรือเป็น argument — อย่ากระจายอยู่ใน path string

## 4. Composition: ตัวเลขที่ใช้ได้จริง

สมมติ canvas 680×383 px (16:9) แล้วสเกลด้วย CSS — ออกแบบในหน่วยนี้

| หลัก | กฎ |
|---|---|
| **Emphasis** | 1 beat มี hero เดียว ใหญ่กว่าอย่างอื่น 2–3 เท่า (ตัวเลข 61–88 px, icon badge 96–144 px, ภาพประกอบไม่เกิน 200 px) |
| **Hierarchy** | ข้อความ 3 ระดับเท่านั้น: hero 39–61, title 25, body/label 16–20 — **ห้ามต่ำกว่า 16 px** สเกลคือ 16/20/25/31/39/49/61 |
| **Balance** | กลุ่มที่มองเห็นต้องอยู่กลางทั้งแนวนอนและแนวตั้งทุกวินาที คู่แบบอสมมาตรได้ถ้าน้ำหนักสมดุล (ของใหญ่สว่างดึงจุดศูนย์ถ่วง — ลดความเข้มมันลง หรือถ่วงฝั่งตรงข้าม) |
| **Unity** | ไอคอนชุดเดียว, สไตล์ภาพเดียว (แบน, เส้น 2–3 px), easing เดียว, ภาษาการเข้าแบบเดียว |
| **Rhythm** | วัตถุชนิดเดียวกันเข้าแบบเดียวกัน — **หักจังหวะเฉพาะ beat สำคัญ** (กระแทก, ขีดฆ่า, เอียง) |
| **Position** | อยู่ใน title-safe: ซ้าย/ขวา 68 px, บน/ล่าง 38 px (ล่าง 72 px เมื่อมีซับ) hero ใกล้ศูนย์กลางเชิงทัศนียภาพ ไม่ชิดขอบ |
| **Space** | ระยะห่างเป็นทวีคูณของ 8 (8/16/24/32) กลุ่มหลักกว้าง 60–85 % ของเฟรม — กลุ่มแคบกลางจออ่านว่า "อึดอัด ข้างว่าง" |

**เช็ก balance จากตัวเลข**: `|margin ซ้าย − ขวา| < 0.03`, `|บน − ล่าง| < 0.06`, `cx` ระหว่าง 0.47–0.53 (ช่วง 0.5 วินาทีที่กำลัง re-centre ระหว่างแอนิเมชัน ยอมรับได้)

**Graphics first, text last** — เสียงพูดมีอยู่แล้วบนจอให้เหลือแค่คำสำคัญ ตัวเลข label คำเดียว หรือ verdict chip เปลี่ยนประโยคเป็นภาพ:
- ตัวเลข → counter วิ่งขึ้น, แท่งกราฟ, ตราชั่งเอียง
- คน/กลุ่มเป้าหมาย → แถว `svgPerson` (ไฮไลต์หนึ่งคน), โทรศัพท์, หมุดแผนที่
- ผิด/ถูก → เส้นเฉียงลากทับไอคอน, กากบาทแดง, เช็กเขียวยืนยัน
- กระบวนการ → funnel ที่มีจุดร่วงลง, ไอคอนคนเดินบนถนน
- เน้น → วงแหวนพัลส์, หัวใจลอยขึ้น, ตราชั่งเอียง

**เคลื่อนไหวเบา ๆ (ลอย พัลส์ วงแหวน) ใส่ได้แค่ hero เท่านั้น** — ไอคอนพื้นหลังเคยใส่แล้วมันทำให้โฟกัสเจือจาง จึงเอาออก

## 5. สี: จ่ายอย่างไรให้ทั้งเรื่องดูเป็นเรื่องเดียว

หลัก **60-30-10**: พื้นผิวกลาง ๆ 90 %, **accent เดียวต่อหนึ่ง scene** (สีของ concept ที่กำลังสอน) และแดง/เขียว**สงวนไว้สำหรับคำตัดสิน** (ผิด/ถูก) เท่านั้น

| id | ชื่อ | mood / เนื้อหา | ค่า accent (โหมดสว่าง) |
|---|---|---|---|
| `clear` | ใส สดชัด | กลาง ๆ ทุกเรื่อง คอร์สออนไลน์ | `#2a78d6 #6250d6 #e76530 #0aa06e #d56a93` |
| `calm` | Digital Calm | เทคโนโลยี การเงิน สุขภาพ ข้อมูล ภาครัฐ | `#2563eb #0f9d9a #7c5cdb #b88309 #5b7087` |
| `earth` | Warm Earth | วัฒนธรรม อาหาร ท่องเที่ยว ชุมชน | `#c2622d #ba8301 #7a8b3a #2f7f7a #8c4a6b` |
| `pop` | Edu Pop | เด็ก การศึกษา โซเชียลสั้น เกม | `#3b82f6 #c67e04 #ec4899 #8b5cf6 #049bb5` |
| `luxe` | Quiet Luxury | แบรนด์ องค์กร รายงานผู้บริหาร | `#9e7b56 #5b6b7f #7d6a8a #6f7f63 #a8644f` |
| `thai` | ไทยโทน | ประวัติศาสตร์ วัฒนธรรมไทย พิพิธภัณฑ์ | `#1f4e8c #ac8807 #c8422c #2e8b6e #6b3f7a` |

**กฎการจ่ายสี**
- concept ที่กลับมาซ้ำได้ช่องของตัวเองและคงไว้ทั้งเรื่อง (เช่น Reach = `ca` ตลอด)
- ช่อง `a` คือสีที่สงบที่สุด ใช้กับ title/outro — สีจัดที่สุดให้เฉพาะ scene สำคัญ
- `thai` ช่อง `c` (ชาด) และ `earth` ช่อง `a` (terracotta) ใกล้แดง "ผิด" — scene ที่มี verdict ให้เลี่ยงช่องนี้ แล้วใช้กากบาทแดงเป็นสัญญาณตัดสินแทน
- **Contrast**: ตัวอักษร ≥ 4.5:1, องค์ประกอบที่ไม่ใช่ข้อความ ≥ 3:1 (accent ทุกชุดถูก tune ให้ ≥ 3.2:1 ทั้งสองโหมดแล้ว)
- palette ที่ผู้ใช้ให้มา (brand / Adobe Color / Coolors) — รับ 5 hex แล้วปรับความสว่างเฉพาะโหมด ให้ hue เดิม พร้อมบอกว่าเปลี่ยนอะไรไปกี่ %

## 6. Animate ชิ้นส่วนของภาพ

- ทั้งวัตถุเข้า: wrap ด้วย `A(p, svg, 'pop|up|zoom|drop')`
- **เส้นวาดตัวเอง**: `class="drawp" pathLength="1" style="--p:.1;--q:.3"` บน path/line/polyline ใดก็ได้ (`--p` จุดเริ่ม, `--q` ความยาว ช่วงเป็นสัดส่วนของ scene)
  - ข้อควรระวัง: `.drawp` ตั้ง `stroke-dasharray` ใน CSS ซึ่งทับ attribute — เส้นประจึงวาดตัวเองไม่ได้ ให้ใช้ `class="an"` (fade) หรือวาดเป็นเส้นสั้น ๆ หลายท่อน
- ขยับเฉพาะชิ้น: ห่อ `<g>` ของชิ้นนั้น แล้วไดรฟ์ด้วย keyframe ที่ใช้ CSS variable, ตั้ง `transform-box:fill-box; transform-origin:center` เพื่อให้หมุนรอบตัวเอง
- **ภาพที่ใช้ซ้ำหลาย scene ซึ่ง accent ต่างกัน** ต้อง pin สีของ concept ไว้ (`ca` สำหรับน้ำ) ไม่ใช่ `var(--acc)` ไม่งั้นน้ำจะกลายเป็นสีแดงใน scene ที่ accent แดง

**ตัวละคร / สัตว์** — ความล้มเหลวอันดับหนึ่งคือสร้างร่างกายเป็นชิ้นเดียวแข็ง ๆ วิธีที่ถูก: หนึ่ง `<g>` ต่อหนึ่งข้อพับ โดยให้ pivot อยู่ที่ origin ของชิ้นนั้น (translate ชั้นนอก, rotate ที่ animate ชั้นใน)

| หลัก | ลงมือ |
|---|---|
| Follow-through | ชิ้นส่วนมาถึงต่างเวลา: หัวตามหลังลำตัว 10–20 %, ผม/เสื้อผ้าตามหลังมากกว่า |
| Arcs | หมุนแขนขารอบข้อ ไม่เลื่อนชิ้นส่วนอินทรีย์เป็นเส้นตรง |
| Secondary action | เล็ก (≤ 10°) เร็วกว่าท่ากลัก ติดกับอะไรที่วางอยู่แล้ว |
| Squash & stretch | ≤ 5 % สายสมจริง, ถึง 20 % สายการ์ตูน, ห้ามกับของแข็ง |
| Anticipation | ท่าสวนทางเล็ก ๆ ก่อนท่าหลัก, ไม่ต้องมีถ้าเป็น loop นิ่ง |

ทุกอย่างอิงนาฬิกาของ scene (`--p/--q/--D`) ห้ามมี loop ของตัวเอง

## 7. Canvas (เมื่อ SVG ไม่ไหวแล้วจริง ๆ)

```js
DRAW.burst = function (g, t, D, w, h) {
  var r = rng(7),                         // re-seed ทุกครั้ง: t เดิม => ภาพเดิม
      u = Math.min(1, t / (.5 * D)), e = 1 - Math.pow(1 - u, 3),
      A = css('--a');
  g.fillStyle = A;
  for (var i = 0; i < 60; i++) {
    var a = r() * 6.283, d = (40 + r() * 110) * e;
    g.beginPath(); g.arc(w/2 + Math.cos(a)*d, h/2 + Math.sin(a)*d*.7, 2 + r()*3, 0, 6.283); g.fill();
  }
};
```

- **เป็นฟังก์ชันบริสุทธิ์ของ `t`** — ไม่มี state ค้างจากเฟรมก่อน, ไม่มี `Math.random`, ไม่มี `requestAnimationFrame` ของตัวเอง ตำแหน่งเป็น closed-form ของ `t` ทั้งหมด (ผลคือ scrub และ mp4 ตรงกันเป๊ะ)
- สุ่มแบบ seeded ด้วย `rng(seed)` — เปลี่ยน seed = ได้อีกลาย, seed เดิม = ได้ลายเดิม
- สีต้องอ่านผ่าน `css('--a')`, `css('--text-primary')` (canvas อ่าน `var()` ไม่ได้)
- **Budget**: หลักร้อยถึงราว 2000 primitive ต่อเฟรม (รันทุกเฟรมตอน scene เล่น)
- canvas ไม่ถูกนับในการ centring อัตโนมัติและไม่ถูกวัดด้วย DOM metric — ให้กล่องขนาดคงที่แล้วตรวจด้วยตาจากภาพ

**Particles ตามเส้นทาง** (น้ำในท่อ): เก็บจุดของ path ไว้ใน array เดียวใช้ทั้ง SVG และ `DRAW`, สเกลด้วย `w / viewBoxWidth`, ตำแหน่งอนุภาค = `(t * speed + k * spacing) mod length` — เฟรมขึ้นกับ `t` ตัวเดียว

## 8. QA: ดูภาพ ไม่ใช่ดูโค้ด

Render ที่ **สถานะจบของแต่ละ beat** และอีก 1–2 จุดที่ของยังวาดไม่เสร็จ แล้วตรวจ:
- วัตถุอ่านออกที่ขนาดนั้นจริง
- สัดส่วนไม่ยืด (height = `w * viewBoxH / viewBoxW`)
- ความหนาเส้นเท่ากับ helper ข้างเคียง
- ทิศทางถูก
- ใช้ได้ทั้ง dark และ light

**ทดสอบภาพ 3 แบบ** (PIL ไม่ต้องลงอะไรเพิ่ม): `Image.open(p).convert('L')` (grayscale), `.point(lambda v: 255*(v>110))` (two-tone), `.resize((64, h*64//w))` (thumbnail)

| ตรวจ | ผ่านเมื่อ |
|---|---|
| Grayscale | hero กับจุดโฟกัสยังแยกจากกันได้ — สีไม่ใช่สิ่งเดียวที่แยกมัน (มีคนแยกแดง/เขียวไม่ออก) |
| Two-tone | เงามืดอย่างเดียวก็ยังบอกได้ว่าคืออะไร |
| Thumbnail 64 px | ยังเดาเงาออกในราวครึ่งวินาที |

## 9. ข้อจำกัดที่ต้องบอกผู้ใช้ตรง ๆ

- ภาพเหมือนจริง กายวิภาคถูกต้อง ใบหน้าและ portrait จะออกมาเป็นสไตล์อยู่แล้ว — บอกล่วงหน้า และเสนอเวอร์ชัน flat/iconic หรือให้ใช้รูปถ่ายเขาแทน
- **อย่าลอกเลียน** ตัวละครมีลิขสิทธิ์ สไตล์ศิลปินที่ยังมีชีวิต หรือโลโก้แบรนด์ด้วยการวาด — โลโก้ให้ใช้ไฟล์ official หรือ glyph กลาง ๆ
- ถ้าโจทย์กำกวม ให้เลือกสไตล์ที่เข้ากับระบบ แล้วบอก assumption หนึ่งบรรทัด — ไม่ต้องยิงคำถามหลายข้อ
- เวลาส่งงานภาพใหม่ บอกด้วยว่า argument ไหนเปลี่ยนอะไร (ขนาด `w`, สี `c`, seed, จำนวน) ผู้ใช้จะได้สั่ง variation ได้

## 10. ของที่ยืมใช้ได้ก่อนวาดเอง

| ระดับ | ที่อยู่ | เก็บอะไร |
|---|---|---|
| Skill tier (ใช้ได้ทุกหัวข้อ) | helper ใน `template.html` | `svgPerson` `svgPhone` `svgCup` `svgShop` `svgFunnel` `svgTarget` `scaleSVG` `bdgS` `pers` `playG` |
| | `assets/illustrations/ui.js` | `tint(c,k)` ปรับ fill อ่อน · `P0(h)` โผล่ตั้งแต่ t=0 · `pill` · `stamp` · `strike(h)` ขีดฆ่า · `vMark(ok,z)` เช็ก/กากบาท · `bdc` badge ไอคอน |
| Series tier (ต่อหัวข้อ) | `<series>/shared/*.js` | ตัวละคร อุปกรณ์ การ์ดของซีรีส์นั้น (prefix `gd*`, `dc*` ...) |
| Episode tier | `<episode>/scenes.js` | ภาพใช้ครั้งเดียว |

ใช้ซ้ำตั้งแต่รอบที่สอง → เลื่อนขึ้นหนึ่งระดับ

**สูตรภาพที่ทดสอบแล้ว**: โทรศัพท์พร้อมปุ่ม play, คนครึ่งตัว, ร้านค้าที่มีกันสาด, ถ้วยกาแฟมีไอ, ตราชั่งสองถาดที่เอียงได้, funnel กับจุดร่วง, เป้าธนูที่มีลูกศรบินเข้า (ขนที่ **หาง**, หัวอยู่ที่กลางเป้า — เคยทำกลับด้าน), โพเดียมสามแท่ง, กราฟ retention ที่มีจุดวิ่งตามเส้น (สเกลที่ container ไม่ใช่ที่จุด: `offset-path` ไม่สนใจ scale ของ parent)

function svgHouse(c, w) {
  return '<svg viewBox="0 0 160 140" width="' + w + '" height="' + Math.round(w * .875) + '" aria-hidden="true">'

    + '<rect x="70" y="92" width="22" height="36" rx="3" fill="var(--surface-2)" stroke="' + c + '" stroke-width="2.5"/>'

    + '<line x1="10" y1="129" x2="150" y2="129" stroke="var(--border-stronger)" stroke-width="3" stroke-linecap="round"/>'
    + '</svg>';
